# Правила работы над проектом (Akinator Clone)

## 1. Главное правило

**"Works on my machine" — не аргумент.**
Весь код должен работать внутри Docker. Если вы добавили библиотеку, но не обновили `requirements.txt` или `Dockerfile` — задача не принята.

## 2. Работа с Git (Git Flow)

Мы бережем ветку `main`. В неё нельзя пушить напрямую.

### Именование веток

Используйте формат: `тип/короткое-название-задачи`

* `feat/game-logic` — новая фича
* `fix/db-connection` — исправление бага
* `docs/readme-update` — документация
* `infra/docker-update` — настройки девопс

### Коммиты

Пишите осмысленные сообщения на английском (или русском, как договоримся).

* ❌ `fix`
* ✅ `fix: resolve database connection timeout`

## 3. Процесс сдачи задачи (Pull Request)

1. Перед созданием PR обновите свою ветку: `git pull --rebase origin main`.
2. Убедитесь, что проект запускается: `docker-compose up --build`.
3. Создайте Pull Request в `main`.
4. Скиньте ссылку в чат тимлиду на ревью.
5. **Мерджить PR может только Тимлид.**

## 4. Бэкенд (Python)

* Все зависимости — в `backend/requirements.txt`.
* Стиль кода: стараемся соблюдать PEP8.
* Если меняете структуру БД — предупредите команду.

## 5. Фронтенд (JS/HTML)

* Весь код лежит в `frontend/src`.
* Не хардкодьте `localhost`! Используйте относительные пути или конфиг, если обращаетесь к API.
